# توثيق مساهمات الفريق

هذا الملف خطة تنفيذ، وليس إثباتاً لمساهمات تمت. لا توجد أسماء أو مراجعات أو تواريخ مساهمات مختلقة. يجب أن ينفذ أعضاء الفريق عملهم الفعلي ويسجلوا مساهماتهم ومراجعاتهم قبل التسليم. متطلبات الوظيفة تسمح بفريق من طالبين إلى خمسة رغم ذكر خمسة في الغلاف؛ وزعوا الأدوار وفق عددكم الحقيقي.

1. أُنشئ مستودع Git محلي للنسخة الحالية بتاريخ التنفيذ الفعلي. يربطه أحد الأعضاء بمستودع خاص ويضيف بقية الفريق.
2. يرفع الشفرة والوثائق والاعتماديات. لا يرفع البيانات الكبيرة أو النموذج المحفوظ مباشرة إلى Git العادي؛ تسلم البيانات ضمن ملف المشروع المضغوط، أو تستخدم Git LFS إذا قرر الفريق ذلك.
3. لكل عضو فرع ومهمة حقيقية: تدقيق البيانات، تحسين التوثيق، تفسير الرسوم، مراجعة التقسيم، أو إضافة اختبار له معنى.
4. يسجل العضو ما نفذه فعلاً باستخدام اسمه وحسابه الحقيقيين؛ لا تُنشأ تعديلات وهمية لزيادة عدد commits.
5. ينشئ طلب دمج ويراجع زميله الكود، مع تعليق يشرح ما راجعه ونتيجة التشغيل. يجب أن يوثق كل طالب مراجعة واحدة على الأقل لكود زميل.
6. تملأ TEAM_CONTRIBUTIONS.csv بالأسماء والأرقام والعمل وروابط المراجعات الفعلية. احذفوا الصفوف غير المستخدمة.
7. يرفق رابط المستودع وسجل التغييرات وأدلة المراجعة بالتسليم وفق طريقة الدكتورة. على كل عضو فهم جميع الأجزاء.

أوامر البداية من داخل مجلد المشروع:

```bash
git status
git log --oneline
git remote -v
git remote set-url origin YOUR_PRIVATE_REPOSITORY_URL
git push -u origin main
```

تستبدل قيمة الرابط بعنوان مستودعكم الحقيقي. بعد الاستعادة من bundle يكون origin موجوداً ويشير إلى ملف محلي، لذلك يستخدم set-url. إذا لم يوجد origin أصلاً، يستخدم git remote add origin متبوعاً بالرابط بدلاً منه. لا يوحي هذا القالب بأن سجلاً جماعياً موجود بالفعل. راجعوا قواعد المقرر بشأن المساعدة الخارجية واذكروها عند وجوب الإفصاح عنها.

## السجل المحلي الحالي

الالتزام الأول يستورد النسخة v2 الموجودة بالفعل، ولا يمثل تاريخ تطويرها السابق. الالتزام التالي يوثق إعداد Git الحالي. مؤلفهما Project Assistant، وليس أحد الطلاب. المستودع محلي ولم يرفع إلى GitHub. يحتفظ ملف git_history.bundle بالسجل الكامل؛ لاستعادته: `git clone git_history.bundle delivery_repo`. البيانات والنتائج تسلّم في حزمة المشروع، والبيانات والنماذج لا تتبع داخل Git.
